## What the set says

- Reaction over explanation; the mechanic is named only when a number or a card forces it.
- Repetition is the main device: a word twice for weight, a chant over the fight, a stack while processing.
- Scoreboards and counts are said aloud as the run goes ("twelve and oh ... thirteen and oh ... fourteen and oh, send it").
- Flexes are hedged ("I'm pretty sure I won. I would be shocked if I haven't."), disbelief is a question ("Excuse me." "What is even happening?").
- Chat is addressed by name once or twice, "man" and "gamers" close sentences.
- "It's over" means the lobby is done and I win; "it's so over" means I lose.
